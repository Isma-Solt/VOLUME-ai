# VOLUME — сайт студии архитектурной визуализации

Одностраничный сайт без сборщиков и зависимостей: чистый HTML, CSS и JavaScript.

## Структура

```
index.html      — разметка всех секций
css/style.css   — стили: переменные, типографика, секции, адаптив
js/main.js      — шапка, мобильное меню, анимации, счётчики, фильтр работ, форма
```

## Запуск

Откройте `index.html` в браузере или отдайте папку любым статическим сервером.

## Интерактив

- Заголовок первого экрана выезжает при загрузке, картинка двигается с лёгким параллаксом.
- Полоса клиентов — бесконечная бегущая строка, останавливается при наведении.
- Карточки услуг подсвечиваются «прожектором», который следует за курсором.
- Карточки процесса, преимуществ, отзывов и цифр приподнимаются с тенью при наведении.
- Карточки работ: масштаб фото и круглая стрелка в углу при наведении, плавная смена при фильтрации.
- Активный пункт меню подсвечивается по мере прокрутки.
- Вопросы в FAQ раскрываются с анимацией высоты.
- Клик по номеру телефона открывает окно подтверждения звонка.
- Адрес открывает Яндекс Карты в новой вкладке.
- Все анимации отключаются при системной настройке «уменьшить движение».

## Развёртывание на сервере

Сайт работает на сервере 138.124.35.110 (Ubuntu, nginx). Файлы лежат в `/var/www/volume`.

Две вещи вынесены на сторону сервера, потому что в России плохо доступны Unsplash и заблокирован Telegram:

- **Картинки** скачаны в папку `img/` и отдаются с нашего сервера, а не с Unsplash.
- **Форма** отправляет заявку не напрямую в Telegram, а на серверный обработчик `api/send.php`,
  который уже пересылает её в Telegram.

Токен бота хранится **не в коде**, а в файле `/etc/volume/bot.env` на сервере — вне папки сайта.
Поэтому папка `api/` спокойно лежит в репозитории и обновляется вместе с остальным кодом.

Обновление сайта — одной командой на сервере:

```bash
/var/www/volume/deploy/update.sh
```

Скрипт делает бэкап, забирает код из GitHub, чинит права и перезагружает nginx.
Откат на предыдущую версию — `/var/www/volume/deploy/rollback.sh`.

Подробная инструкция (первичная настройка сервера, dev-версия, бот, домен и HTTPS):
[`deploy/DEPLOY.md`](deploy/DEPLOY.md).

## Заявки в Telegram

Заявку из формы принимает `api/send.php` на сервере и пересылает её боту. Чтобы сообщения доходили:

1. Бот уже создан (`@VOLUME_autorization_bot`), токен и chat id прописаны в `api/send.php` на сервере.
2. Получатель должен один раз открыть бота и нажать **Start**, иначе Telegram не даёт боту писать.

Сообщение приходит в таком виде:

```
🏠 Новая заявка с сайта VOLUME

👤 Имя: Иван Петров
📞 Телефон: +79991234567
🏗 Тип объекта: Частный дом

💬 О проекте:
Дом 240 м², нужны 3 ракурса к концу месяца

🕒 08.09.2026, 20:40
```

## Замена контента

- Изображения лежат в папке `img/`. Чтобы поставить свои рендеры, замените файлы и обновите `src` в `index.html`.
- Телефон, почта и адрес встречаются в шапке, секции «Заявка» и подвале `index.html`.
- Цены на услуги и тексты правятся прямо в разметке.
