# VOLUME — сайт студии архитектурной визуализации

Одностраничный сайт без сборщиков и зависимостей: чистый HTML, CSS и JavaScript.

## Структура

```
index.html      — разметка всех секций
css/style.css   — стили: переменные, типографика, секции, адаптив
js/main.js      — шапка, мобильное меню, анимации, счётчики, фильтр работ, форма
```

## Запуск

Откройте `index.html` в браузере или отдайте папку любым статическим сервером.

## Интерактив

- Заголовок первого экрана выезжает при загрузке, картинка двигается с лёгким параллаксом.
- Полоса клиентов — бесконечная бегущая строка, останавливается при наведении.
- Карточки услуг подсвечиваются «прожектором», который следует за курсором.
- Карточки процесса, преимуществ, отзывов и цифр приподнимаются с тенью при наведении.
- Карточки работ: масштаб фото и круглая стрелка в углу при наведении, плавная смена при фильтрации.
- Активный пункт меню подсвечивается по мере прокрутки.
- Вопросы в FAQ раскрываются с анимацией высоты.
- Клик по номеру телефона открывает окно подтверждения звонка.
- Адрес открывает Яндекс Карты в новой вкладке.
- Все анимации отключаются при системной настройке «уменьшить движение».

## Заявки в Telegram

Форма отправляет заявку через Telegram Bot API прямо из браузера, бэкенд не нужен.
Настройка занимает пять минут:

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и логин бота.
   BotFather пришлёт токен вида `123456789:AAF...`.
2. Откройте своего нового бота и нажмите **Start**, иначе он не сможет вам писать.
3. Узнайте свой числовой id: откройте [@userinfobot](https://t.me/userinfobot), он ответит числом вида `123456789`.
   Если заявки нужны в группу, добавьте бота в группу и возьмите id группы (начинается с `-100`).
4. Впишите токен и id в начало `js/main.js`:

```js
const TELEGRAM = {
  botToken: '123456789:AAF...',
  chatId: '123456789',
};
```

Сообщение приходит в таком виде:

```
🏠 Новая заявка с сайта VOLUME

👤 Имя: Иван Петров
📞 Телефон: +79991234567
🏗 Тип объекта: Частный дом

💬 О проекте:
Дом 240 м², нужны 3 ракурса к концу месяца

🕒 08.09.2026, 20:40
```

Важно: токен лежит в открытом JS-файле, его увидит любой, кто откроет исходник сайта.
Через него можно только слать сообщения от имени бота в ваш чат, доступа к аккаунту он не даёт.
Если бот начнёт спамить, отзовите токен командой `/revoke` в BotFather и впишите новый.

## Замена контента

- Изображения подключены с Unsplash по прямым ссылкам. Для продакшена положите свои рендеры в `img/` и обновите `src`.
- Телефон, почта и адрес встречаются в шапке, секции «Заявка» и подвале `index.html`.
- Цены на услуги и тексты правятся прямо в разметке.

## Адаптив

- Десктоп: от 1025px
- Планшет: до 1024px
- Мобильный: до 768px, дополнительные правки до 480px
