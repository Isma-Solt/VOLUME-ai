# VOLUME — сайт студии архитектурной визуализации

Одностраничный сайт без сборщиков и зависимостей: чистый HTML, CSS и JavaScript.

## Структура

```
index.html      — разметка всех секций
css/style.css   — стили: переменные, типографика, секции, адаптив
js/main.js      — шапка, мобильное меню, анимации, счётчики, фильтр работ, форма
```

## Запуск

Откройте `index.html` в браузере или отдайте папку любым статическим сервером.

## Подключение формы

Заявка обрабатывается функцией `sendLead` в `js/main.js`. Сейчас она только логирует данные в консоль.
Замените её тело на запрос к вашему бэкенду, например:

```js
function sendLead(formData) {
  return fetch('/api/lead', { method: 'POST', body: formData })
    .then((response) => { if (!response.ok) throw new Error(response.status); });
}
```

## Замена контента

- Изображения подключены с Unsplash по прямым ссылкам. Для продакшена положите свои рендеры в `img/` и обновите `src`.
- Телефон, почта и адрес встречаются в шапке, секции «Заявка» и подвале `index.html`.
- Цены на услуги и тексты правятся прямо в разметке.

## Адаптив

- Десктоп: от 1025px
- Планшет: до 1024px
- Мобильный: до 768px, дополнительные правки до 480px
